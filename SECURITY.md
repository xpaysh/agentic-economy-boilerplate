# Security Policy

## Reporting a Vulnerability

Please report security issues privately via GitHub's Security Advisory feature or email security@xpay.sh.

**Do not** open public issues for security vulnerabilities.

## Response Timeline

- Acknowledgment: 48 hours
- Initial assessment: 7 days
- Fix timeline: Depends on severity

## Scope

This policy covers the boilerplate code in this repository. For issues with specific protocol implementations (x402, AP2, etc.), please also contact the respective protocol maintainers.
