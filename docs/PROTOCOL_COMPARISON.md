# Protocol Comparison

## Quick Reference

| Feature | x402 | AP2 | ACP | Mastercard |
|---------|------|-----|-----|------------|
| Payment Type | Crypto | Traditional | Traditional | Card Network |
| Setup Complexity | Low | Medium | Medium | High |
| Transaction Speed | Fast | Medium | Medium | Medium |
| Best For | Micropayments | Enterprise | E-commerce | Established merchants |

## When to Use Each Protocol

### x402
- Crypto-native applications
- Micropayments and pay-per-use
- Web3 integrations

### AP2 (Agent Payment Protocol)
- Enterprise B2B transactions
- High-value transactions
- Regulated environments

### ACP (Agentic Commerce Protocol)
- E-commerce integrations
- Multi-vendor marketplaces
- Consumer applications

### Mastercard
- Existing card infrastructure
- Global merchant acceptance
- Traditional payment flows

## Choosing a Protocol

1. **Payment method**: Crypto (x402) vs Traditional (AP2/ACP/Mastercard)
2. **Transaction size**: Micro (x402) vs Standard (others)
3. **Integration effort**: Quick start (x402) vs Full integration (Mastercard)
